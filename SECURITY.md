# Security Policy

## Supported versions

Security fixes are intended for the latest stable release line.

| Version | Security updates |
| --- | --- |
| Latest stable release (currently 1.4.2) | Yes |
| Older releases | Not guaranteed |

Use the latest release when possible. The supported version may change as new
releases are published.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue, discussion,
or pull request.

Use GitHub's
[private vulnerability reporting](https://github.com/sap112233/Clear_My_PC/security/advisories/new)
for this repository if it is available. If it is unavailable, contact the
maintainer through the contact options on the
[maintainer's GitHub profile](https://github.com/sap112233) and ask for a
private way to share the report.

Include, when possible:

- The affected version, platform, and relevant configuration.
- The impact and the conditions needed to reproduce the issue.
- A minimal proof of concept or steps to reproduce, avoiding access to or
  exposure of anyone else's data.
- Any known workaround.

Please give the maintainer a reasonable opportunity to investigate and
prepare a fix before sharing vulnerability details publicly. Do not access,
modify, or delete data that is not yours while investigating.

## What to expect

The maintainer will review reports as capacity allows and may ask for more
information. If a report is accepted, the maintainer will work toward a fix
and coordinate disclosure when practical. If it is declined or is not
considered a security issue, the maintainer will explain that decision when
possible. There is no dedicated security response team or guaranteed
acknowledgement or resolution time.

This project is maintained by volunteers. Reports are appreciated, but
reporters should not assume a particular response timeline.
